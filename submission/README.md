# Submission: Нейрофизиологическая диагностика ПТСР

## Требования

- **Python 3.13** (проверено на 3.13.5)
- Пакеты из `requirements.txt`

## Установка

```bash
pip install -r requirements.txt
```

## Использование

### Прогон по всем испытуемым

```bash
python predict.py <input_dir> <output_csv>
```

**Пример:**

```bash
python predict.py /data/test_subjects /output/predictions.csv
```

**Результат:** CSV с колонками `subject_id, ptsd_probability` — по одной
строке на испытуемого. Вероятность непрерывная в [0, 1].

**Ожидаемое время:** ~2–3 секунды на испытуемого (6 EDF-файлов).

### Предсказание для одного испытуемого

```python
from predict import predict, load_model
from pathlib import Path

model = load_model(Path("final_model.pkl"))
prob = predict(model, Path("/path/to/subject_dir"))
print(prob)  # вероятность ПТСР в [0, 1]
```

## Модель

Ансамбль двух пайплайнов, обученных на парах ПТСР vs контроль:

| Компонент | Признаки | Вес |
|---|---|---|
| Logistic Regression (L1, C=0.1) | 730 (без поведенческих) | 0.65 |
| SVM (RBF, C=1.0, gamma=0.005) | 726 (без поведенческих и `n_clean_segments`) | 0.35 |

**Итоговая вероятность:** `0.65 × p_LR + 0.35 × p_SVM`.

Отбор признаков (SelectKBest, k=20) выполняется внутри каждого фолда LOSO.

### Типы признаков

- Спектральные мощности (delta, theta, alpha, beta, gamma) — абсолютные,
  относительные, логарифмические
- Пиковая частота и мощность альфа-ритма
- Апериодический наклон спектра (log-log фит 2–40 Гц)
- Асимметрии (Fp1/Fp2, T3/T4, O1/O2)
- Функциональная связность (coherence) в theta/alpha/beta
- Контрасты покой ↔ задача Шульте

### Метрики (LOSO-валидация)

| Метрика | Значение |
|---|---|
| ROC-AUC (ПТСР vs контроль) | **0.949** [95% ДИ: 0.899, 0.986] |
| Sensitivity (ПТСР) | **0.84** |
| Specificity (контроль) | **0.94** |
| FPR на Соматоформных | **0.097** |

**Валидация:** leave-one-subject-out (LOSO) — все записи одного
испытуемого всегда по одну сторону разбиения.

## Обработка ошибок

- Если папка испытуемого пуста или EDF-файлы повреждены —
  `predict()` возвращает `0.5` (нейтральное значение).
- Если в папке меньше 6 файлов — используются доступные; агрегаты
  считаются по имеющимся пробам.
- `run()` продолжает работу при ошибке на отдельном испытуемом,
  записывая `NaN` в CSV.
